## 3. 검수 절차

1. 검수자는 자신의 만세력 도구로 fixture의 팔자를 산출해 엔진 팔자와 대조한다.
2. 격국·용신·기신·강약을 검수자의 학파 기준으로 판정하고 엔진 출력과 비교한다.
3. 감지된 패턴(combo/cross/flow) 목록을 보고, 실전 상담에서 의미 있는 조합인지 판정한다.
4. 해당 패턴의 `body.short`·`body.medium` 문구를 읽고 정확성·실전성·안전성을 채점한다.
5. 판정 결과를 아래 기록 형식으로 남긴다.

## 4. 판정 기준

- **pass**: 엔진 출력과 문구가 검수자의 학파 기준에서 문제없음
- **revise**: 방향은 맞으나 표현·강도·조건이 수정 필요 — `SUGGESTED` 문구 제시
- **reject**: 명리적으로 틀리거나 상담에 해가 되는 수준 — 근거를 반드시 기록

## 5. 기록 형식

```markdown
## {fixture-id} — {entry-id 또는 '엔진 출력'}
- reviewer: {이름/소속}
- basis: {학파·교재·실전 근거}
- date: {YYYY-MM-DD}
- verdict: pass | revise | reject
- note: {자유 서술}
- suggested: {revise 시 대체 문구}
```

기록은 `content/reviews/{YYYYMMDD}-expert.md`에 추가한다. 검수가 끝난 엔트리만 `status: published` 승격 후보가 된다.
